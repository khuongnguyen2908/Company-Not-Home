# Nội dung game

Đặt file `content.xlsx` vào thư mục này để thay đổi câu chữ trong game (tên vai, lời thoại bot, tên phòng, thông báo...).

1. Mở game, thêm `?content` vào cuối địa chỉ để vào **Công cụ nội dung**.
2. Bấm **Xuất Excel**, mở file trên Google Sheets (tải lên Google Drive rồi mở bằng Google Sheets), sửa cột "Nội dung".
3. Tải về dạng `.xlsx`, quay lại công cụ bấm **Nhập Excel**. Công cụ báo lỗi nếu câu quá dài hoặc thiếu chỗ trống `{tên}`.
4. Bấm **Thử trong game** để xem ngay trên máy mình.
5. Ưng rồi thì bấm **Tải file cho GitHub**, đưa file `content.xlsx` vào thư mục này (Add file → Upload files → Commit). Trang game tự build lại.

Xóa file này đi thì game quay về nội dung mặc định.
